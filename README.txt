SafarSathi update

1. Back up your existing app.py.
2. Copy this app.py into your SafarSathi project folder.
3. Copy the included images folder into the same project folder (merge it with your existing images folder; do not delete destination photo folders).
4. Keep your existing db.py, security.py, and .env unchanged.
5. Activate the virtual environment and run: streamlit run app.py

Package photo structure:
images/jaipur/jaipur1.jpg ... jaipur5.jpg
images/goa/goa1.jpg ... goa5.jpg
images/manali/manali1.jpg ... manali5.jpg
Use the folder name matching the destination. JPG, JPEG, PNG, and WEBP are supported.
